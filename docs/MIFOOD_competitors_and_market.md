# Конкуренты и позиционирование МИФУД

МИФУД является нишевым продуктом для конкретного вуза — МИФИ и его филиалов. Конкуренция ведётся не с другими приложениями, а с альтернативными способами организации питания студентов внутри и за пределами кампуса.

Бренд и продукт привязаны к МИФИ — название, специфика расписания, интеграции с инфраструктурой вуза. Выход за пределы экосистемы МИФИ не планируется и является сознательным выбором.

Количественные оценки распределения студентов между альтернативами в данном документе не приводятся. Полевые данные подлежат получению в ходе пилотного запуска.

---

## 1. Поведенческие альтернативы для студента

Основные способы организации обеда студента МИФИ:

| Альтернатива                       | Что предлагает студенту               | Преимущество МИФУД                                     |
|------------------------------------|---------------------------------------|--------------------------------------------------------|
| Очередь в столовой                 | Привычный способ без изменений        | Отсутствие очереди, заказ заранее                      |
| Кафе и фастфуд вокруг МИФИ         | Удобство, разнообразие                | Ниже цена, отсутствие потери времени на дорогу         |
| Доставка готовой еды               | Получение на месте                    | Ниже цена, отсутствие ожидания курьера                 |
| Контейнер из дома                  | Экономия, контроль состава            | Шире выбор, отсутствие подготовки накануне             |
| Пропуск обеда                      | Экономия времени                      | Сопоставимая скорость при полноценном питании          |

Каждая из перечисленных опций представляет собой потерянный заказ для столовой МИФИ. МИФУД формирует канал возврата этой аудитории в столовую вуза.

## 2. Косвенные технологические конкуренты

Перечисленные ниже продукты иногда упоминаются в связи с МИФУД, однако решают принципиально иные задачи.

### iiko

Система автоматизации общественного питания: касса, складской учёт, бухгалтерия, управление персоналом, рецептуры. Целевой клиент — рестораны, кафе, корпоративные столовые. Базовая подписка от 2 500 ₽ в месяц за рабочее место, мобильное приложение для конечных пользователей реализуется через дополнительные модули с суммарной стоимостью 10 000–30 000 ₽ в месяц на одну точку.

МИФУД относится к customer-facing слою и не пересекается с iiko по основной функциональности. При наличии iiko в столовой МИФИ возможна интеграция через API: заказы из МИФУД поступают в iiko как обычные позиции, касса пробивает чек.

### R-Keeper

POS-система от UCS Group, старейший игрок российского рынка HoReCa. Используется в крупных сетях ресторанов. Категория и позиционирование аналогичны iiko.

### Poster

Облачная POS-система для малого бизнеса в общественном питании. Относится к той же категории back-office решений.

### SberFood

Сервис Сбера для оплаты в партнёрских ресторанах с интеграцией программы лояльности СберПрайм. Целевая аудитория — городские рестораны общего доступа. Конфликт с МИФУД минимальный, поскольку закрытые кампусные столовые не входят в зону интереса сервиса.

### Агрегаторы доставки (Я.Еда, Delivery Club, Самокат)

B2C-приложения для доставки готовой еды из внешних ресторанов. Косвенный конкурент: забирают студента у столовой к внешним заведениям, тогда как МИФУД возвращает аудиторию обратно в вузовскую столовую. Конкуренция ведётся за поведение пользователя, не за конкретный заказ.

### Сервисы бронирования столов

TableBooker, Restoplace, Tomesto и аналогичные продукты ориентированы на бронирование столов в ресторанах для проведения мероприятий. С функциональностью МИФУД — резервирование места в общем зале столовой на время обеда — не пересекаются.

## 3. Прямые конкуренты

### eda.mephi.ru — «Еда в МИФИ»

Официальный сайт МИФИ для просмотра меню столовых и кафе на территории вуза. Технологически реализован на Vue.js. Функциональность ограничена пассивным отображением меню: списки точек питания, состав блюд на дату. Меню обновляется нерегулярно.

Сравнение функциональности:

| Функция                                | eda.mephi.ru             | МИФУД                                       |
|----------------------------------------|--------------------------|---------------------------------------------|
| Просмотр меню                          | Реализован                | Реализован                                  |
| Актуальность данных                    | Нерегулярные обновления   | Управляется администратором в реальном времени |
| Онлайн-заказ                           | Отсутствует               | Реализован                                  |
| Бронирование стола                     | Отсутствует               | Реализовано                                 |
| Онлайн-оплата                          | Отсутствует               | Через ЮKassa                                |
| Уведомления о готовности заказа        | Отсутствуют               | Real-time через SSE                         |
| Управление заказами для кухни (KDS)    | Отсутствует               | Реализовано                                 |
| Установка на устройство (PWA)          | Отсутствует               | Реализована                                 |
| Аналитика спроса для администрации     | Отсутствует               | Запланирована в roadmap                     |

Существование eda.mephi.ru подтверждает признание задачи цифровизации питания студентов на уровне самого вуза. МИФУД развивает это направление от пассивного просмотра меню к полноценному сценарию заказа, оплаты и получения с бронированием стола. Возможен сценарий технической интеграции: меню из eda.mephi.ru используется как источник данных, заказы и платежи обрабатываются на стороне МИФУД.
